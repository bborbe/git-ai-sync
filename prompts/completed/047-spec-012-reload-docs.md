# Document the converging launchd reload and record it in the changelog

<summary>
- The launchd service guide no longer describes a bare bootout-then-bootstrap reload.
- It states that install boots the job out, polls until launchd reports the job gone, then bootstraps.
- It states that the poll is bounded and that a raced bootstrap is retried once.
- It states that a job that never disappears, or a bootstrap that fails twice, exits non-zero with the manual command.
- The troubleshooting "you upgraded the binary" section describes the same converging reload.
- The changelog gains an `## Unreleased` section with one fix bullet covering the reload and the status `never` fix.
- No code, test or CI file changes.
</summary>

<objective>

</objective>
